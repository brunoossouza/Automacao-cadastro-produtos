# 🚀 Automação de Cadastro de Produtos com Python

## 📌 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de automatizar o cadastro de produtos em um sistema web utilizando Python.

A automação realiza todo o processo automaticamente, desde a abertura do navegador até o preenchimento dos campos do sistema com os dados contidos em uma base CSV.

---

## ⚙️ Funcionalidades

✅ Abrir o navegador automaticamente
✅ Acessar o sistema web
✅ Realizar login automático
✅ Ler uma base de dados CSV
✅ Preencher formulários automaticamente
✅ Cadastrar múltiplos produtos em sequência

---

## 🛠️ Tecnologias Utilizadas

* Python
* PyAutoGUI
* Pandas

## 📊 Base de Dados

O projeto utiliza um arquivo CSV contendo as informações dos produtos:

* código
* marca
* tipo
* categoria
* preço
* custo
* observações

## 💡 Objetivo do Projeto

O principal objetivo foi praticar automação de processos utilizando Python, simulando tarefas repetitivas realizadas manualmente em empresas.

Além disso, o projeto ajudou no aprendizado sobre:

* automação de tarefas
* manipulação de dados
* integração entre Python e sistemas web
